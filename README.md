# NEXORA — Fashion E-commerce UI

A responsive fashion e-commerce concept website

- Modern fashion-inspired UI
- Responsive product grid
- Product category filters
- Product search
- Interactive shopping cart
- Mobile navigation menu
- Newsletter form UI

- JavaScript
